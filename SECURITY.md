# Security

This is an early, local-only MVP. No paid security audit or production safety
certification is claimed. Never submit real logs, credentials, private keys,
cookies, personal data, or production Compose files in issues or pull requests.

Report a reproducible issue using a minimized synthetic fixture, expected and
actual behavior, Python version, and operating system. If a future repository
host enables private vulnerability reporting, use that channel for sensitive
vulnerabilities. No private reporting address or monitoring SLA is configured
in this unpublished project; do not invent a recipient or send sensitive data.

Only inspect files you own or are authorized to analyze. The program does not
upload data. Review README limitations before relying on findings or sharing
outputs. Keep original input and generated reports in a private directory.
